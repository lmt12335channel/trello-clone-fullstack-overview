Trello Clone - Dự án Full-Stack (MERN)

Dự án này được chia thành hai kho lưu trữ riêng biệt. Vui lòng truy cập các liên kết dưới đây để xem mã nguồn chi tiết cho từng phần:

🚀 Frontend (React.js & Material UI): github.com/lmt12335channel/trello-clone-frontend

⚙️ Backend (Node.js & Express.js): github.com/lmt12335channel/trello-clone-backend

✨ Tổng quan tính năng

Quản lý công việc trực quan: Giao diện kéo và thả (Drag & Drop) mượt mà để di chuyển các thẻ công việc giữa các cột.

Tương tác động: Thêm, xóa, và chỉnh sửa các cột và thẻ trong thời gian thực.

Lưu trữ bền bỉ: Mọi thay đổi đều được lưu trữ an toàn trong cơ sở dữ liệu MongoDB thông qua các API do backend cung cấp.

Giao diện tùy biến: Hỗ trợ nhiều chế độ hiển thị (Sáng, Tối, và theo Hệ thống) để phù hợp với sở thích của người dùng.

🏗️ Kiến trúc dự án

Dự án được xây dựng theo mô hình client-server:

Client (Frontend): Một ứng dụng React độc lập (Single Page Application) chịu trách nhiệm hiển thị giao diện và xử lý tương tác người dùng.

Server (Backend): Một máy chủ Node.js/Express cung cấp các API RESTful để frontend có thể thực hiện các thao tác CRUD (Create, Read, Update, Delete) với dữ liệu.

🏁 Hướng dẫn cài đặt và chạy dự án

Để chạy dự án hoàn chỉnh, bạn cần cài đặt và khởi động cả hai phần backend và frontend. Vui lòng làm theo hướng dẫn chi tiết trong tệp README.md của từng kho lưu trữ tương ứng.
